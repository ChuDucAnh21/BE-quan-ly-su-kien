## UC27 – Đăng ký tham gia sự kiện

| Trường                     | Nội dung                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên Use Case**           | Đăng ký tham gia sự kiện (Mua vé)                                                                                                                                                                                                                                                                                                                                                                 |
| **Tác nhân**               | User, Organizer, Admin                                                                                                                                                                                                                                                                                                                                                                            |
| **Mục đích**               | Cho phép người dùng đăng ký tham gia sự kiện. Hệ thống tự phân luồng: vé miễn phí cấp ngay, vé trả phí tạo link thanh toán PayOS                                                                                                                                                                                                                                                                  |
| **Mức độ ưu tiên**         | Cao                                                                                                                                                                                                                                                                                                                                                                                               |
| **Điều kiện kích hoạt**    | Người dùng nhấn "Đăng ký" hoặc "Mua vé" trên trang chi tiết sự kiện                                                                                                                                                                                                                                                                                                                               |
| **Điều kiện tiên quyết**   | Đã đăng nhập. Sự kiện ở trạng thái PUBLISHED. Chưa hết chỗ. Sự kiện chưa bắt đầu. Người dùng chưa đăng ký sự kiện này                                                                                                                                                                                                                                                                             |
| **Điều kiện thất bại**     | Đăng ký không thành công. Hệ thống hiển thị lỗi cụ thể                                                                                                                                                                                                                                                                                                                                            |
| **Điều kiện thành công**   | Registration + Payment được tạo. Nếu miễn phí → Ticket được sinh ngay. Nếu có phí → checkoutUrl được trả về                                                                                                                                                                                                                                                                                       |
| **Luồng sự kiện chính**    | 1. Người dùng nhấn "Đăng ký/Mua vé". 2. Frontend gửi POST /registrations với {eventId}. 3. Hệ thống kiểm tra sự kiện PUBLISHED. 4. Hệ thống kiểm tra chưa qua startTime. 5. Hệ thống kiểm tra soldTickets < capacity. 6. Hệ thống kiểm tra User chưa đăng ký. 7. Hệ thống giữ chỗ: soldTickets += 1. 8. Hệ thống sinh mã đăng ký (UUID 8 ký tự viết hoa). 9. Hệ thống phân nhánh theo ticketPrice |
| **Luồng sự kiện thay thế** | 9a. ticketPrice = 0 (Miễn phí): Tạo Registration (CONFIRMED) + Payment ảo (provider=SYSTEM, amount=0, status=SUCCESS) + Sinh Ticket (ACTIVE) với qrCode = UUID 36 ký tự. 9b. ticketPrice > 0 (Trả phí): Tạo Registration (PENDING_PAYMENT) + Gọi PayOS SDK tạo link checkout + Lưu Payment (PENDING, checkoutUrl) + Trả checkoutUrl cho Frontend để redirect                                      |
| **Luồng sự kiện ngoại lệ** | 3a. Sự kiện chưa công bố hoặc đã bắt đầu → EVENT_NOT_STARTED (400). 5a. Hết chỗ → TICKET_SOLD_OUT (400). 6a. Đã đăng ký → ALREADY_REGISTERED (400). 9b1. Organizer chưa cấu hình PayOS → PAYMENT_CONFIG_NOT_FOUND (404)                                                                                                                                                                           |

## UC28 – Hủy đăng ký tham gia sự kiện

| Trường                     | Nội dung                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên Use Case**           | Hủy đăng ký tham gia sự kiện                                                                                                                                                                                                                                                                                                                                                     |
| **Tác nhân**               | User, Organizer, Admin                                                                                                                                                                                                                                                                                                                                                           |
| **Mục đích**               | Cho phép người dùng hủy vé miễn phí hoặc vé trả phí nhưng chưa thanh toán để nhường chỗ cho người khác                                                                                                                                                                                                                                                                           |
| **Mức độ ưu tiên**         | Trung bình                                                                                                                                                                                                                                                                                                                                                                       |
| **Điều kiện kích hoạt**    | User nhấn "Hủy vé" trên trang vé đã đăng ký                                                                                                                                                                                                                                                                                                                                      |
| **Điều kiện tiên quyết**   | Đã đăng nhập. Vé thuộc sự kiện miễn phí (ticketPrice = 0) HOẶC vé có phí nhưng trạng thái đang là PENDING_PAYMENT. Sự kiện chưa diễn ra.                                                                                                                                                                                                                                         |
| **Điều kiện thất bại**     | Vé không bị hủy. Hệ thống hiển thị lỗi                                                                                                                                                                                                                                                                                                                                           |
| **Điều kiện thành công**   | Registration → CANCELLED. Ticket → INVALID (nếu đã sinh vé free). Payment → CANCELLED (nếu có). soldTickets -= 1 (nhả chỗ)                                                                                                                                                                                                                                                       |
| **Luồng sự kiện chính**    | 1. User nhấn "Hủy vé". 2. Hệ thống xác nhận. 3. User xác nhận hủy. 4. Frontend gửi POST /registrations/{id}/cancel. 5. Hệ thống kiểm tra quyền. 6. Hệ thống kiểm tra vé là Free hoặc Chưa thanh toán. 7. Hệ thống chuyển Registration → CANCELLED, Payment (nếu có) → CANCELLED, Ticket (nếu có) → INVALID. 8. Hệ thống nhả chỗ: soldTickets -= 1. 9. Hệ thống trả về thành công |
| **Luồng sự kiện thay thế** | 3a. User nhấn "Không" → Không hủy                                                                                                                                                                                                                                                                                                                                                |
| **Luồng sự kiện ngoại lệ** | 5a. Vé trả phí đã thanh toán (CONFIRMED) → CANNOT_CANCEL_PAID_TICKET (400). 5b. Đã qua thời gian bắt đầu sự kiện → EVENT_NOT_STARTED (400)                                                                                                                                                                                                                                       |

| **Mức độ ưu tiên**         | Cao                                                                                                                                                                                                                                                                                                                                                                              |
| **Điều kiện kích hoạt**    | Người dùng được chuyển hướng đến cổng thanh toán PayOS sau khi đăng ký hoặc từ danh sách đơn hàng chờ                                                                                                                                                                                                                                                                            |

| **Luồng sự kiện ngoại lệ** | 4a. Giao dịch hết hạn (quá thời gian quy định) → PayOS báo lỗi hết hạn trên giao diện cổng thanh toán.                                                                                                                                                                                                                                                                           |

| **Điều kiện tiên quyết**   | Đơn hàng tồn tại trong CSDL                                                                                                                                                                                                                                                               |
| **Điều kiện thất bại**     | Không kết nối được PayOS                                                                                                                                                                                                                                                                  |
| **Điều kiện thành công**   | Trạng thái đơn hàng được đồng bộ chính xác với PayOS                                                                                                                                                                                                                                      |

Vẫn PENDING → Trả "PENDING"                                                                                                                |
| **Luồng sự kiện ngoại lệ** | 2a. orderCode không tồn tại → PAYMENT_NOT_FOUND (404). 4a. Không kết nối được PayOS → UNCATEGORIZED_EXCEPTION (500)                                                                                                                                                                       |

| **Mức độ ưu tiên**         | Cao                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Điều kiện kích hoạt**    | Staff quét mã QR trên điện thoại khách hàng bằng camera                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Điều kiện tiên quyết**   | Đã đăng nhập. Vé tồn tại và ở trạng thái ACTIVE. Người quét có quyền (Admin/Organizer/Staff phân công)                                                                                                                                                                                                                                                                                                                                                           |
